# Промпты для параллельной реализации в Codex

## Как запускать работу

Используйте отдельный Git worktree/чат Codex для каждой параллельной задачи. Один агент сначала выполняет стартовую задачу и волну 0, фиксирует контракты. После этого независимые агенты работают в своих каталогах. Агенты не должны одновременно менять одни и те же файлы.

Во все задачи передавайте путь к репозиторию и требуйте сначала прочитать:

- `docs/SPEC.md` — копия `01_TECHNICAL_SPEC.md`;
- `docs/ARCHITECTURE.md`;
- `docs/CONTRACTS.md`;
- `AGENTS.md`.

Токены, API-ключ Codex Sale, приватный SSH-ключ и рабочие пароли в промпты не вставляются. Канал `@dnrGStore`, ID канала `1004444554310`, имя бота `@Dnr_GStore_bot`, VPS `138.124.84.40`, SSH-пользователь `root`, админ ID `8231768970` и endpoint Codex Sale можно указывать. Секреты агент читает только из env-файла, который оператор создает вручную.
